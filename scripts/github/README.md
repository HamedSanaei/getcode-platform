# GitHub roadmap bootstrap

After pushing the starter and authenticating `gh`:

```bash
python scripts/github/bootstrap_github.py --repo HamedSanaei/getcode-platform --dry-run
python scripts/github/bootstrap_github.py --repo HamedSanaei/getcode-platform
```

The script is designed to avoid duplicate labels, milestones and issues by exact title. Review the dry run first.
