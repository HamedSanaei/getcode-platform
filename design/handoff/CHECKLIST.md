# Penpot -> Next.js handoff checklist

- [ ] Penpot component/page is approved.
- [ ] All responsive breakpoints/states are shown.
- [ ] Loading, empty, error, disabled and success states are covered where applicable.
- [ ] Keyboard/focus behavior is specified.
- [ ] Color contrast and reduced-motion implications are checked.
- [ ] Tokens are mapped; no arbitrary one-off values without justification.
- [ ] RTL/Persian layout has been reviewed.
- [ ] Host-brand differences are token-based.
- [ ] API data requirements are documented without embedding business logic in the UI.
- [ ] Visual regression baseline is created/updated when available.
