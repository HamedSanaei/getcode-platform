# Penpot -> Next.js handoff checklist

- [x] Penpot components/pages pass the documented M01 design review.
- [x] The authoritative live-HTML route-family inventory is recorded; no active public family is silently inferred.
- [x] Objective structure is compared using live HTML/CSS and the preserved Numberland snapshot.
- [x] Intentional GetCode scope/brand differences are documented as product/domain decisions.
- [x] All responsive breakpoints/states are shown.
- [x] Loading, empty, error, disabled and success states are covered where applicable.
- [x] Keyboard/focus behavior is specified.
- [x] Color contrast and reduced-motion implications are checked.
- [x] Tokens are mapped; no arbitrary one-off values without justification.
- [x] RTL/Persian layout has been reviewed.
- [x] Host-brand differences are token-based.
- [ ] Owner review is recorded for visual differences that cannot be objectively verified from HTML/CSS and the preserved snapshot.
- [ ] API data requirements are documented without embedding business logic in the UI.
- [ ] Visual regression baseline is created/updated when available.
